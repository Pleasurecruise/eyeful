# Agent workspace

This directory holds development-process state, not application behavior.

- `POLARIS.md` defines the product outcome and the hard measures that gate every change.
- `specs/` defines the evidence required for feedback-sensitive changes.
- `evidence/` holds temporary verification evidence (ignored by Git); remove it after acceptance.

Do not store conversations, credentials, machine-specific paths, product facts already owned by
`docs/`, or copies of external workflow instructions here.
